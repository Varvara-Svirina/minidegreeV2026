# minidegreeV2026
1. вопрос: есть ли связь между отделом Met, типом объекта (classification) и вероятностью того, что у объекта указан автор (artistDisplayName)?
API Met отдает для каждого объекта 3 поля: отдел (departament), тип объекта (classification) и имя автора (artistDisplayName). Это позволяет собрать выборку и сравнить, как наличие/отсутствие автора соотносится с отделом и типом объекта. В данном случае "вероятность того, что у объекта указан автор" -- это доля объектов с непустым автором внутри каждой группы "отдел + тип объекта". Мы сравним эти доли между отделами и внутри каждого отдела (между разными типами объектов) и посмотрим на корреляцию.
2. почему выбран именно этот API? - Met Collection API не требует ключа или токена, выдает структурированные метаданные
кто создает данные? - сам музей, то есть записи отражают решения музейных специалистов
что считается одной записью? - один музейный объект: название, автор, отдел, тип объекта, дату итд. 
что источник описывает плохо? - так как это собрание одного конкретного музея, то эти данные не отражают ситуацию со всеми объектами искусства по всему миру всех времен (выборка сильно ограничена).  К тому же отсутствие автора в карточке объекта может означать не его фактическое отсутствие, а решение работников музея сделать такое обозначение.
